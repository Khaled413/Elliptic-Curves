# Elliptic Curves: The Mathematical Foundation of Modern Cryptography

![image](https://github.com/user-attachments/assets/cf713463-386a-472c-8e79-36524c98dedf)

A modern, interactive web application that demonstrates and visualizes elliptic curves and their applications in cryptography. Built with Next.js, TypeScript, and Tailwind CSS.

## 🌟 Features

- **Interactive Visualizations**: Real-time rendering of elliptic curves with adjustable parameters
- **Educational Content**: Comprehensive explanations of elliptic curve mathematics and cryptography
- **Practice Section**: Interactive exercises to understand elliptic curve operations
- **Modern UI**: Beautiful, responsive design with smooth animations
- **Dark Mode**: Optimized for comfortable viewing

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or later)
- pnpm (recommended) or npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/elliptic-curves.git
cd elliptic-curves
```

2. Install dependencies:
```bash
pnpm install
# or
npm install
```

3. Run the development server:
```bash
pnpm dev
# or
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- **Frontend Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **UI Components**: Shadcn/ui
- **Math Rendering**: Custom Math Equation Component

## 📚 Educational Content

The application covers several key topics in elliptic curve cryptography:

1. **Mathematical Foundation**
   - Elliptic curve equations
   - Point operations (addition, multiplication)
   - Group theory basics

2. **Cryptographic Applications**
   - ECDSA (Elliptic Curve Digital Signature Algorithm)
   - ECDH (Elliptic Curve Diffie-Hellman)
   - TLS/SSL protocols

3. **Real-World Applications**
   - Blockchain technology
   - Secure messaging
   - IoT security
